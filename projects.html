Sales Data Analysis For a Convenience Store

This project was done by me and two of my classmates in the course ITEC 2600, we created a MATLAB data analysis system for a convenience store using the simulated weekly sales data. We used tables, statistical analysis, loops and conditional logic to automate the calculation of important information like revenue, top selling products and profits through charts and tables

Academic Mangement Support System

This project was developed by me and three other classmates in the course ITEC 3230. The project was about creating a useful daily application and we chose to do an academic management support system for students to assist them in organizing their tasks and deadlines, which leads to better stress management. Part of the project was gathering information from students so that we could develop the system in the best possible way. The project include all the links for the diagrams, designs and prototypes.

Exoplanet Detection and Analysis

This project was done in NATS 1880, in which I used light curve data that was given to me to find possible exoplanets with the transit method. The project included scientific and mathematical ideas and laws to be applied like Kepler's Third Law, calculating orbital periods, transit depth and planetary radius and more. The goal was to evaluate potential habitability.
